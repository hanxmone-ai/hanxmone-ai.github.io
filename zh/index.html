streaming-chat-demo

TypeScript · Node · SSE · 开源

回答逐字出现的聊天应用：小型 Node 服务器把任何兼容 OpenAI 接口的大模型以 SSE 转发给浏览器，15 KB 的前端把流式内容实时渲染成 Markdown，不依赖任何框架。

  • 点"停止"会同时取消对模型的调用，之后不再生成、不再计费。
  • 显示首字延迟和每秒 token 数；49 个测试，覆盖 SSE 边界情况和 Markdown 安全。
