Open source and products

sunmi-webview-bridge

Android · Kotlin · open source

An Android app that opens any web page on a Sunmi POS terminal and lets it use the built-in barcode scanner and receipt printer through a small JavaScript API.

  • Text, barcodes, QR codes and images, with one call per receipt.
  • Works with existing pages that already call the older API.

llm-router-lite

Python · LLM gateway · open source in November

A self-hosted gateway that gives apps one OpenAI-style API in front of OpenAI, Claude, DeepSeek, Ollama and others.

  • Routing with retries, fallback to another provider and a circuit breaker; streaming included.
  • A separate key, model list and monthly budget for each client app, with a usage dashboard.

Public repository from 1 November 2026

streaming-chat-demo

TypeScript · Node · server-sent events · open source

A chat app where answers appear token by token as the model writes them. A small Node server relays any OpenAI-compatible API as server-sent events; a 15 KB client renders the stream as Markdown, without frameworks.

  • Stop cancels the call to the model too, so nothing is generated or paid for afterwards.
  • Shows time to first token and tokens per second; 49 tests, including SSE edge cases and Markdown safety.
